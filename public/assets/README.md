### How to Edit or Replace Images

1. **Find the folder** for the section you want to modify (e.g. `public/assets/dining/` for food photos, or `public/assets/header/` for the logo).
2. **Replace the file** with your new image using the **exact same filename and file extension** (or update the filename in the corresponding component).
3. The website will immediately update without any layout distortion or confusion!
