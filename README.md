# Beyond Sands Resort · Coastal Sanctuary

> **"Coastal calm at the blue hour."**  
> Wake to palms, wind, and the sea's quiet hush. Premium coastal resort with private verandahs and curated local experiences located at Kelva Beach, Palghar, Maharashtra, India.

---

## ✨ Features & Architecture

- **Awwwards-Calibre Visual Design:** Luxury typography (`Playfair Display`, `Cormorant Garamond`, `Plus Jakarta Sans`, `DM Sans`), balanced color palettes (Champagne Gold `#C49A65`, Deep Coastal Navy `#17365D`, Warm Ivory `#F5EFEB`), and WCAG AAA compliant contrast.
- **Cinematic Atmosphere:** Scroll-driven sky system simulating the transition from coastal midday to deep blue-hour twilight, with custom ambient coastal soundscape and luxury trailing cursor.
- **Interactive Suite Showcase:** Pinned horizontal rail with live room detail modal, specifications drawer, and real-time stay price calculator with meal plan selection.
- **Scroll-Driven Dining Experience:** Maharashtrian coastal pure vegetarian culinary showcase featuring rotating thali presentations on scroll scrub with interactive full menu drawer.
- **High-Resolution Gallery & Lightbox:** Masonry resort gallery with category filters (Rooms, Nature, Amenities, Architecture) and full-screen lightbox navigation.
- **Complete Route Coverage:** Dedicated sub-pages for Accommodations, Dining, Experiences, Weddings & Events, Offers, Location, Contact, and FAQ.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animation:** [GSAP](https://greensock.com/gsap/) with ScrollTrigger
- **Audio:** Web Audio API with procedural coastal ambient synthesis
- **Icons:** Bespoke Lucide-style luxury vector SVG system

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
